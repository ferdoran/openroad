# Third-party material in this repository

Attribution index for code and assets that OpenRoad did not author. Bundled
dependencies pulled by Cargo are not listed individually here — run
`cargo about generate` (see `deny.toml`) for the full generated notice covering
the resolved dependency tree.

OpenRoad itself is **GPL-3.0-or-later** throughout; see `LICENSE`.

## Vendored source

| Component | Path | Upstream | Licence |
|---|---|---|---|
| Blowfish block cipher | `bevy_pk2/src/pk2/blowfish.rs` | [RustCrypto/block-ciphers](https://github.com/RustCrypto/block-ciphers) | Apache-2.0 OR MIT, © RustCrypto Developers |
| Blowfish block cipher | `client/src/net/blowfish.rs` | [RustCrypto/block-ciphers](https://github.com/RustCrypto/block-ciphers) | Apache-2.0 OR MIT, © RustCrypto Developers |

Both are adapted copies rather than verbatim ones: the API surface was reduced,
and the SRO-specific key handling around them (the PK2 salt fold in
`gen_final_blowfish_key_inplace`, the keyless `new` in the client copy) is
OpenRoad's own. Upstream's licence terms require the copyright notice to
accompany the code, which is why each file carries a header. The full texts are in
`licenses/RustCrypto-MIT.txt` and `licenses/RustCrypto-Apache-2.0.txt`.

MIT and Apache-2.0 are both GPL-compatible, so vendoring this into a
GPL-3.0-or-later tree is fine — the notice obligation is what survives, and it is
satisfied above.

> Known duplication: the two copies are near-identical, differing only in that
> the client's `new` takes no salt. Collapsing them onto the upstream `blowfish`
> crate would remove both the duplication and this attribution burden. (The
> unused `blowfish` dependency `client` used to declare has been removed.)

## Art and textures

| Asset | Path | Origin | Licence |
|---|---|---|---|
| Grass billboard cards | `assets/foliage/grass_{a..d}.png` | Composited from [ambientCG Foliage006](https://ambientcg.com/view?id=Foliage006) by `tools/src/bin/gen_foliage_cards` | CC0 1.0 |
| Water normal map | `assets/textures/water_normal.png` | Procedurally generated by `tools/src/bin/gen_water_normal` | OpenRoad's own |
| Cursor sheet and crops | `.raw/Cursors.png`, `.raw/Cursor.xcf`, `assets/cursors/*.png` | Generated with OpenAI `gpt-image`; the PNG carries its C2PA Content Credentials manifest | See note below |

**On the cursor art:** it is machine-generated, and in several jurisdictions —
the United States among them — a purely AI-generated image attracts no
copyright, so OpenRoad makes no ownership claim over it and it may not be
protected by the repository's licence the way authored code is. It is recorded
here so its provenance travels with it rather than being inferred.

**No Silkroad Online assets are distributed with this project.** Everything the
client renders from the game — models, textures, UI art, sounds, text data — is
read at runtime from PK2 archives the user supplies themselves. See
`assets/PLACE_SILKROAD_ASSETS_HERE`.

## Documentation sources

Format and protocol documentation under `docs/` cites its sources per file.
`CONTRIBUTING.md` lists each source's licence class and what that class permits — most
importantly that sources with no declared licence are all-rights-reserved by
default, so facts and field layouts may be learned from them but their text and
code may not be copied.
