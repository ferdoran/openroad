# SRO Client Folder Structure (Example)

This is a reference layout of a Silkroad Online client folder used by this project.
The client expects the PK2 files to be available locally.

Example structure:
```
VSRO_Client/
  Data.pk2
  GFXFileManager.dll
  Map.pk2
  Media.pk2
  Music.pk2
  Particles.pk2
  Pk2Writer.dll
  replacer.exe
  setting/
  silkcfg.dat
  Silkload.dat
  silkroad.exe
  Silkroad.ico
  SilkroadLauncher.exe
  sro_client.exe
  xtrap.dat
```
